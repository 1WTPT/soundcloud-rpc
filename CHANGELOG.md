# История версий

## v0.1.0 — 12 ноября 2026

Первая предварительная версия для Windows 11 x64.

- Отдельное окно SoundCloud на Edge WebView2.
- Название песни, исполнитель, обложка и ссылка в Discord Rich Presence.
- Удаление активности на паузе и при закрытии программы.
- Автоматические попытки подключения к Discord.
- Сохранение браузерного профиля SoundCloud.
- Готовый EXE и сборка через GitHub Actions.

Полная проверка с реальным воспроизведением и карточкой Discord ещё требуется. Подробности — в `VERIFICATION.md`.

# SoundCloud RPC v0.1.5

Убрано повторение названия песни после слова «Слушает».

- Имя активности содержит два невидимых символа вместо названия трека.
- В самой карточке сохранены название песни крупным текстом, исполнитель, обложка и прогресс.
- Системный трей Open / Close сохранён.

Для обновления полностью закрой прежнюю версию через **Close** в трее и запусти новый **SoundCloudRPC.exe**.

Скрытие суффикса использует невидимые символы: фактический результат зависит от обработки текста клиентом Discord и требует проверки. Контрольная сумма EXE находится в `SHA256SUMS.txt`.

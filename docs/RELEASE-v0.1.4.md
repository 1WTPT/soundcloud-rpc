# SoundCloud RPC v0.1.4

Добавлен системный трей Windows с иконкой приложения.

- **Open** — показывает окно SoundCloud. Также работает двойной щелчок по значку.
- **Close** — полностью закрывает приложение, прекращает музыку и убирает активность Discord.
- **Крестик окна** — скрывает окно в трей; музыка и Rich Presence продолжают работать.

Значок может находиться под стрелкой скрытых значков Windows рядом с часами. Для полного выхода используй **Close** в его меню.

Полностью закрой прежнюю версию и скачай **SoundCloudRPC.exe** ниже. Вход в SoundCloud сохраняется. Windows 10/11 x64; требуется WebView2 Runtime.

Автоматические тесты проверяют скрытие окна и порядок завершения RPC. `SHA256SUMS.txt` содержит контрольную сумму EXE.

# SoundCloud RPC v0.1.2

Компактная карточка песни и все улучшения обложек, таймера и иконки Windows.

## Карточка Discord

- **Первая строка — название трека**, вместо `SoundCloudRPC`.
- **Ниже — исполнитель**, без дублирования названия третьей строкой.
- Тип активности **«Слушает»**, временные метки для прогресса и синхронизация после перемотки.

Точный вид карточки и текст её системной шапки определяет Discord. Отдельного поля для произвольной фразы «Слушает в SoundCloud» в RPC нет. Программа передаёт название трека в поле имени активности, а автора — в описание.

## Также включено

- Обложки 500×500 при наличии; при ошибке сохраняется исходная картинка. Более крупные изображения не уменьшаются.
- Обновлённая иконка приложения: знак немного увеличен, добавлены девять размеров ICO и явная иконка окна. Изображение приложения Discord не менялось.
- В требования добавлена Windows 10 x64 наряду с Windows 11 x64. Отдельный ручной тест Windows 10 пока не выполнен.

## Как обновиться

1. Закрой старую версию и скачай **SoundCloudRPC.exe** ниже.
2. Открой настольный Discord, запусти новый EXE и включи песню в окне приложения.
3. Если закреплённая иконка осталась старой, открепи прежний ярлык и закрепи запущенную новую версию.

Вход в SoundCloud сохраняется. Python и расширения не требуются; нужен Microsoft Edge WebView2 Runtime. EXE не подписан сертификатом издателя.

Предварительная версия: точное оформление карточки Discord и работу на Windows 10 ещё нужно проверить вручную. `SHA256SUMS.txt` содержит контрольную сумму EXE.

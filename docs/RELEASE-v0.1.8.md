# SoundCloud RPC v0.1.8

- Панель **Reload / Restart** стала тёмной: приглушённый текст, спокойное наведение и тонкая граница вместо яркой белой полосы.
- В кнопках используется округлый **Nunito Regular**. Шрифт встроен в EXE; отдельно устанавливать его не нужно.
- Убрана повторная передача названия песни в подписи обложки (`large_text`), которая могла давать третью строку в Discord. Основные поля сохранены: название — `details`, автор — `state`, обложка — отдельным изображением.
- Сохранены независимый трей, Reload и Restart, таймаут чтения страницы и выход при зависшем окне.

Панель проверена настоящим рендером WinForms. Прошли 21 тест Python и 9 тестов считывания плеера. Автоматические проверки подтверждают, что в данных RPC название передаётся один раз, а автор и обложка сохраняются. Вид карточки после правки в живом Discord здесь не проверялся.

Для обновления полностью закрой старое приложение через **Close** в трее, затем скачай и запусти **SoundCloudRPC.exe** ниже. Сохранённый вход SoundCloud остаётся в прежнем профиле. Контрольная сумма находится в **SHA256SUMS.txt**.

# SoundCloud RPC v0.1.7

Исправлена задержка Close при зависшем окне.

- **Независимый трей:** меню работает в отдельном потоке от окна SoundCloud.
- **Close:** сразу запрашивает выход и очистку RPC; если приложение зависло, через 3 секунды завершается только собственный процесс. Закрытие соединения прекращает отправку активности, её исчезновение в интерфейсе Discord может занять время.
- **Reload:** перезагрузка текущей страницы, кнопка над сайтом и пункт в трее.
- **Restart:** завершение старого процесса и новый запуск с сохранением профиля SoundCloud.
- В надписи «Слушает …» вместо песни используется невидимое имя. Совместимость такого отображения зависит от клиента Discord.

Проверено настоящее меню Windows, скрытие и восстановление окна. При искусственно замороженном главном потоке независимый Close завершил тестовый процесс за 3 секунды. Автоматические тесты проверяют таймаут чтения страницы, управление RPC и восстановление.

Конкретная причина зависания у пользователя пока неизвестна. Обновление устраняет бесконечное ожидание чтения страницы и добавляет независимый способ выхода.

Для обновления полностью закрой прежнюю версию и скачай новый EXE ниже. Если старая версия не отвечает даже на Close, заверши её через Диспетчер задач. `SHA256SUMS.txt` содержит контрольную сумму EXE.

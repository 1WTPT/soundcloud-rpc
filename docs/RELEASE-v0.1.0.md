# SoundCloud RPC v0.1.0

Первая предварительная версия: музыка из SoundCloud в твоём профиле Discord.

## Установка

1. Скачай **SoundCloudRPC.exe** из файлов ниже.
2. Открой настольный Discord и включи отображение текущей активности.
3. Запусти приложение и включи песню в его окне SoundCloud.

Python и расширения браузера не требуются. Application ID уже настроен.

## Возможности

- Название трека, исполнитель и доступная обложка.
- Автоматическое обновление при смене песни.
- Удаление активности на паузе.
- Переподключение к Discord и сохранение входа в SoundCloud.

## Требования и ограничения

Windows 11 x64, настольный Discord и Microsoft Edge WebView2 Runtime. Музыку нужно слушать в окне приложения — другие окна браузера не отслеживаются. EXE не подписан сертификатом издателя.

Это предварительный релиз: сборка, загрузка сайта и автоматические тесты проверены, полный сценарий с реальной песней и карточкой Discord пока не подтверждён. Если встретишь ошибку, создай issue с версией приложения и шагами воспроизведения.

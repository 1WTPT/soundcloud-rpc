# SoundCloud RPC v0.1.3

Исправлен перепутанный порядок названия песни и исполнителя в карточке Discord.

- **Название трека — крупной строкой.**
- **Исполнитель — ниже мелким текстом.**
- Текст **«Слушает …»** сохранён: имя активности по-прежнему содержит название трека.

Обложки, прогресс, иконка приложения и требования Windows 10/11 x64 сохранены из предыдущей версии.

## Обновление

Закрой старую версию, скачай **SoundCloudRPC.exe** ниже и запусти его. Вход в SoundCloud сохраняется.

Автоматические тесты проверяют поля карточки; её фактический вид после исправления ещё нужно подтвердить в Discord. `SHA256SUMS.txt` содержит контрольную сумму EXE.

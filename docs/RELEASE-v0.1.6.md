# SoundCloud RPC v0.1.6

- **Reload** над страницей и в трее — перезагрузить текущую страницу SoundCloud. Музыка при этом может остановиться.
- **Restart** — закрыть приложение с очисткой RPC и запустить заново, сохранив профиль SoundCloud.
- Чтение зависшей страницы больше не блокирует поток управления RPC бесконечно. В заголовке появляется подсказка Reload / Restart.
- Сохранено сокращение надписи до «Слушает» через невидимое имя активности. Результат зависит от клиента Discord.

При полностью зависшем главном потоке Windows кнопки также могут не отвечать: в этом случае потребуется завершение процесса через Диспетчер задач. Причина зависания у пользователя пока не установлена; найденное бесконечное ожидание чтения страницы ограничено таймаутом.

Для обновления полностью закрой прежнюю версию через Close в трее и запусти новый EXE. `SHA256SUMS.txt` содержит контрольную сумму.

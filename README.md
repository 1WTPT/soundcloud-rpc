SoundCloud RPC — небольшое приложение для Windows 10 и 11 x64. Оно открывает SoundCloud в отдельном окне и передаёт данные звучащего трека в Discord. Без браузерных расширений, ручной смены статуса и токенов аккаунта.

> Музыку нужно слушать **в окне приложения**. Воспроизведение в других окнах Chrome, Edge или Firefox эта версия не отслеживает.

## Что умеет

| Возможность | Поведение |
| --- | --- |
| Текущий трек | Название, исполнитель и доступная обложка в Rich Presence |
| Качество обложки | Загрузка варианта 500×500, если он доступен; крупные исходники сохраняются |
| Прогресс | Тип «Слушает», позиция и длительность трека, обновление при перемотке |
| Компактная карточка | Название трека первой строкой, исполнитель ниже; имя приложения не подставляется в эти строки |
| Смена песни | Автоматическое обновление активности |
| Пауза | Удаление активности до возобновления |
| Перезапуск Discord | Автоматические попытки переподключения |
| Вход в SoundCloud | Отдельный браузерный профиль сохраняется между запусками |
| Простая установка | Один `.exe`, без установки Python |

## Быстрый старт

1. Открой [последний релиз](../../releases/latest) и скачай **SoundCloudRPC.exe**.
2. Запусти настольный **Discord** и разреши отображение текущей активности в его настройках.
3. Открой **SoundCloudRPC.exe** и включи песню в появившемся окне SoundCloud.

Крестик скрывает окно в системный трей, музыка продолжает играть. Нажми правой кнопкой на значке рядом с часами: **Open** возвращает окно, **Close** полностью завершает программу и убирает активность Discord. Двойной щелчок также открывает окно. Значок может находиться под стрелкой скрытых значков Windows.

Над страницей находится тёмная панель с округлым шрифтом Nunito; шрифт встроен в EXE. На панели и в трее есть **Reload** для перезагрузки сайта и **Restart** для полного перезапуска приложения с сохранением входа. Перезагрузка страницы может остановить воспроизведение. Трей работает в отдельном потоке: при зависании окна используй **Close** или **Restart** именно в трее. Если штатный выход не завершается, через 3 секунды приложение завершает только собственный процесс.

Для публичной сборки Application ID уже указан. Пользователю не нужно создавать приложение в Discord Developer Portal.

### Требования

- Windows 10 x64 (рекомендуется 22H2) или Windows 11 x64. Совместимость Windows 10 основана на требованиях зависимостей; отдельная ручная проверка на Windows 10 пока не выполнена.
- Настольное приложение Discord.
- Интернет и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). Обычно WebView2 уже установлен в Windows 11.

Python нужен только для работы с исходниками. EXE не подписан сертификатом издателя. 32-битная Windows не поддерживается этой сборкой.

## Частые вопросы

<details>
<summary><strong>Почему отдельное окно SoundCloud?</strong></summary>

Так программа получает данные текущего плеера и исходный URL обложки без расширений браузера и без загрузки изображений на сторонний хостинг. Можно переходить между страницами SoundCloud: активность берётся из нижнего плеера.

</details>

<details>
<summary><strong>Активность не появилась — что проверить?</strong></summary>

Убедись, что открыт настольный Discord, разрешено отображение активности, а музыка играет именно в окне SoundCloud RPC. Проверь статус подключения в заголовке окна. Обновления обычно занимают 2–6 секунд, попытки переподключения выполняются с интервалом 10 секунд.

Если проблема сохраняется, приложи описание ошибки и версию приложения к issue. Диагностический журнал находится в `%LOCALAPPDATA%\SoundCloudRPC\app.log`; просмотри его перед публикацией и удали личные данные.

</details>

<details>
<summary><strong>Почему нет обложки или кнопки перехода?</strong></summary>

Обложка зависит от данных, доступных в плеере SoundCloud. Если картинки нет, программа отправляет текстовую активность. Discord может скрывать кнопку перехода от владельца активности, показывая её другим пользователям.

</details>

<details>
<summary><strong>Нужно снова входить в SoundCloud?</strong></summary>

У приложения отдельный браузерный профиль: вход из Chrome или Edge в него не переносится. После входа в SoundCloud данные сохраняются локально. Некоторые способы входа через сторонние сервисы могут иметь ограничения во встроенном браузере.

</details>

## Данные и конфиденциальность

Программа передаёт Discord название, исполнителя, ссылку и URL обложки текущего трека. Эти сведения могут быть видны другим людям в твоей активности. Пароли и токены Discord программе не нужны.

Данные сайта и локальные настройки находятся в `%LOCALAPPDATA%\SoundCloudRPC`. Программа не запускает локальный HTTP-сервер и не предоставляет странице SoundCloud Python API.

## Статус проекта

**v0.1.8 — ранняя версия.** Сборка Windows и автоматические тесты проверяются в GitHub Actions; также проверена загрузка SoundCloud в WebView2. Полный сценарий с реальной песней, обложкой и карточкой Discord пока не подтверждён. Подробности — в [отчёте о проверке](VERIFICATION.md).

Разметка SoundCloud может измениться и потребовать обновления считывания плеера. Программа передаёт временные метки начала и конца трека для полосы прогресса. Если длительность недоступна, таймер не отправляется. Точный вид карточки определяет Discord; совместное прослушивание и другие возможности официальной интеграции Spotify не реализованы.

В RPC задан тип «Слушает». Произвольную фразу в системной шапке, например «Слушает в SoundCloud», независимо от остальных строк задать нельзя: её формирует клиент Discord.

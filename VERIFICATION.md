# Проверка этой сборки

- Среда: Windows 11 x64, Python 3.12.10.
- 12 тестов Python проверяют фильтрацию данных, допустимые URL обложек, смену трека, паузу, возобновление, ограничение частоты, переподключение, временные метки, перемотку, некорректную длительность и компактные строки карточки.
- Девять тестов JavaScript прошли: чтение нижнего плеера, пауза, отказ на постороннем домене, Media Session fallback, крупная обложка и ошибка её загрузки, позиция и длительность.
- PyInstaller 6.22.3 успешно собрал `SoundCloudRPC.exe`.
- В исходной версии проверен запуск Edge WebView2 и загрузка реальной страницы SoundCloud Discover. При этой проверке Discord RPC был заменён тестовым объектом, чтобы не менять активность пользователя.
- В сборку добавлен Application ID владельца `1570439393188122756`.
- Workflow v0.1.0 и v0.1.1 успешно завершились на GitHub; обновление v0.1.2 дополнительно проверяется workflow своего тега.
- Реальная музыка, авторизация SoundCloud, отображение обложки и полосы прогресса в Discord здесь не проверены. Ручной тест на Windows 10 не выполнен.

Перед публичным релизом выполните ручную проверку из README.
